# Modul Embedded System — ECS Lab

Kode pendamping modul pelatihan. Setiap folder sesuai dengan bab di modul PDF.

## Daftar Isi
- [Pengenalan Mikrokontroler](bab-pengenalan-mikrokontroler/)
- [RTOS](bab-rtos/)

## Perangkat
- Board: ESP32 TTGO T-Call
- Arduino IDE 2.x, ESP32 core versi 3.x

## Cara Pakai
1. Klik tombol hijau **Code** → **Download ZIP**
2. Ekstrak, buka file `.ino` sesuai bab
3. Pilih board "ESP32 Dev Module", lalu Upload
